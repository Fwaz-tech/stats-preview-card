# Stats Preview Card

A responsive stats preview card built with HTML and CSS.

## Features

* Responsive layout for desktop and mobile screens
* Clean and modern card design
* Custom fonts using Google Fonts
* Responsive image with a purple overlay
* Business statistics section

## Built With

* HTML5
* CSS3
* Flexbox
* Media Queries
* CSS Custom Properties
